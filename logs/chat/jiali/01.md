## Key decisions and rationale

- **Roles:** Student and TA, where a TA with `isManager` is a TA Coordinator.
  `employeeId`, `isManager`, `src/libconnect-mp4` and the `libconnect-mp4`
  project ID keep their names, to limit code churn. Agent proposal, accepted by
  the user.
- **Routes:** `/student/dashboard` and `/ta/dashboard`, with no redirects from
  the old paths. The user approved this with `role-based-dashboards` v0.5.
- **Book catalog:** the `member-catalog-search` spec is retired. A future Bug
  FAQ spec may reuse its search patterns. User-approved.
- **GitHub links:** the server never fetches a ticket's GitHub link; only
  pasted files go to the LLM. Agent decision in `Overview.md`, approved with
  the amendment.
- **Rate limits:** SoC issued one key, so the 90/min provider cap is shared.
  Each environment's global limit is 40/min, at most 45. Per user: 5/min and
  50/day. User-confirmed.
- **No new dependencies for `ai-gateway`:** it uses Node `fetch` and
  hand-written validators. Part of the approved spec.
- **`package.json`:** build-only packages move to `devDependencies`, so
  `npm audit --omit=dev` is meaningful. User-approved.
- **Environments:** two new Firebase projects.
