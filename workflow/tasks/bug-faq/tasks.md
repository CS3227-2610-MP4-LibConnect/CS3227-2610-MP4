- [x] **T01 — Resolved-only bounded search and FAQ detail store.** Implement the search query constrained to stored `RESOLVED`, ordered by `createdAt` descending and document ID ascending; scan at most 100 tickets per request and return up to 20 matches in the selected title/tag field. Add a resolved-only detail read returning title, tags, fix note, and bounded replies, with pagination tied to that ticket. Safely skip malformed data and verify reply membership. Add/verify the exact composite index config, without deployment. Cover statuses, multiple owners, sparse/dense matching, page boundaries, token opacity/tampering/session rotation, cursor binding, detail projection, reply pagination, malformed data, exact bounds, and index shape. (R2–R3; scenarios 2–5.)

- [x] **T02 — Protected search and detail APIs.** Add the search route and dedicated FAQ detail route before the ticket-ID route. Validate all inputs and decrypt each token only with the current authenticated session, Student ID, token purpose, and query/reference bindings. Reject tampered, expired, cross-session, wrong-purpose, cross-search, and cross-ticket tokens safely. Recheck active Student identity/account on every request, enforce stored `RESOLVED` on detail reads, use no-store responses, generic safe errors, and server-derived Student/TA speaker labels. Do not expose IDs or names as speaker metadata; message bodies, including names typed in them, render literally. Test all denials, all statuses, forged authorization inputs, logout/session rotation, safe failures, and projections. Depends on T01. (R2–R3; scenarios 2–5.)

Add UI tests for order, requests, literal user content, pagination, navigation, and absence of owner-only actions or identifiers. Depends on T02. (R1, scenarios 1, 3, 6.)

- [x] **T04 — Integration verification, guides, and evidence.** Use synthetic multi-owner tickets across all four statuses, multiple search batches, and multiple reply pages to verify status and projection boundaries. Record versions, changed files, exact checks/results, deviations, and risks.
